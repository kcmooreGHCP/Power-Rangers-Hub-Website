Do this first

1. Install once. Quit InDesign and run INSTALL_RC12_11.command. It updates the existing ~/Documents/SET_819 workspace, backs up the current launcher/scripts, and preserves all maps, assets and outputs.
2. Open the active file. In InDesign: Window → Utilities → Scripts → User → SET_819 → 00_START_SET_819.jsx.
3. Build in this order. Store shell → align/lock → smart backbone/templates → map approved visuals → check store → choose publish scope → build Guide → SET IRL/VMA.

Do not run old RC12.10 / 2C / 3C bridge scripts. RC12.11 absorbs the useful logic into one governed Smart Backbone + Template Manager.

The operating model

LOCKED LINE MAP Walls, doors, columns and fixed architecture + SMART SPACE BACKBONE Existing governed SET connectors enriched with fixture dimensions, Space Planning color, reusable template key, movability and export rules + APPROVED PRESENTATION VISUALS PSD / PNG / CC Library asset attached to the physical connector = STORE-SPECIFIC EXECUTION MAP ↓ TOC + DETAIL PAGES + CHANGE LOG + SET IRL + VMA

What stays locked

Architecture, calibrated scale, Blue Yonder IDs, stable placement labels, fixed building elements.

What can update

Movable fixture status, mapped visual, collection/product story, action icons, line-list details, current floorset outcome.

Rule: Build the physical store once. Update the merchandise repeatedly. Learn from every floorset.

The template unlock

The uploaded cookie-cutter script was a useful starter, but it required a manual Blue Yonder CSV and could create a second disconnected connector field. RC12.11 integrates the idea safely into the existing SET record.

Action 1

Register / refresh Smart Backbone

Automatically reads the current indexed store snapshot. It enriches every existing governed connector with a reusable template key, template class, front/back requirement, movability, Space Planning color and 1000px export rule. It does not move or duplicate the connector.

Action 2

Build reusable template library

Creates a cumulative master library as more stores are registered. Surfaces, floor fixtures and forms receive equal FRONT/BACK holders. Cabinets receive one governed holder. IDMS snippets, INDD, PDF and CSV manifest are produced.

Action 3

Match assets to templates

Reads the current Asset Index or automated CC Library catalog and creates an exact/review/unmatched report. SET does not silently guess or remap a file.

Map + connect approved visuals

Visual Map Mode: Select the real map target, preview the asset and map it. Best for spatial thinkers.
Match Board: See connectors and assets side by side. Match one visual across a run or map selected 01→N.
Automated CC Library: Use 3B to auto-ingest the .cclib/.cclibs package. No staging document and no one-by-one drag/drop.
Smart Template Manager: Use 3C after alignment/lock and before large-scale mapping. The template definition remains attached when the presentation asset is mapped and normalized.

Placement numbers such as S01, FF30, FM30 and C100 belong to the physical connector, not the image filename.
