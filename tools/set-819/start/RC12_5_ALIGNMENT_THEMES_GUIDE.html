SET LOOP RC12.5

Fit the map. Inspect the fixture. Design the room.

This update bundles the true CC Library workflow from RC12.4 with a five-point, no-rotation map fit; readable Script Labels; room/zone theme and hero setup; and a consistent front/back Brand Guide layout.

1. Five-point map fit

Open the indexed shell, then run D — 5-POINT AUTO FIT.

Select the connector closest to the back-left interior reference. Create the cyan anchor and drag it to the matching map location.
Repeat for back-right, front-left, front-right and center.
Run Auto Fit. X and Y scale independently. Rotation is disabled.
Use Wider, Narrower, Taller, Shorter or arrow nudges only when needed. Then lock and clear all guides.

The architectural line map never moves. On-floor connectors and mapped presentations move together. Support/off-floor records do not influence the fit.

2. Script Label details

Select a connector and open Window → Utilities → Script Label. The label now shows room, zone, placement, fixture, Blue Yonder ID, capacity, base minutes, status and mapped asset.

Use 4B Inspect / Refresh Script Label Details for a readable popup or to restamp the whole file.

3. Room / zone themes

Run 4C Room / Zone Theme + Hero Setup.

Use the space-planning default color or enter custom CMYK. Select the creative hero image for the chapter-opening page. SET writes the governed choices to 01_SOURCE/ZONE_THEMES.csv.

4. Store-facing Brand Guide changes

  • Every room/zone starts with a designed chapter page: hero image, highlighted map, and a linked “What to Set” list.
  • The room/zone accent uses the space-planning default or your custom theme.
  • Surfaces, floor fixtures and forms use one consistent wide layout.
  • When front and back companion files exist, both receive equal full-size visual space.
  • Store direction, action icons, product/line-list content and SET IRL stay compact and useful.
  • Internal timing and Blue Yonder details remain in the manifest, not on the store execution page.

5. True CC Library

Use 3B True CC Library Staging + Capture. Drag approved graphics from the real CC Libraries panel into the staging frames, then capture local PNG automation copies. The CC Library remains the approved source.

Normal test order

  1. Open one indexed store shell.
  2. Run five-point fit and lock it.
  3. Run Normalize Proportions + Map Labels.
  4. Inspect one connector through Script Label.
  5. Set one room/zone theme and hero.
  6. Rebuild the Brand Guide.
  7. Confirm the room opener, front/back surface page, action area and interactive navigation.
