The architecture

Do not create an agent for every person or tiny task.
Create one Control Tower, domain agents only where knowledge/tools/permissions differ, and child agents for small repeatable tasks.

Every agent works on the same release contract and stops at its owner boundary. Original sources stay untouched. Working changes happen through flows. Final decisions stay human-owned.
