Confidential Content Treatment

When content is marked Confidential · Assigned Use Only, SET Loop can apply a subtle watermark overlay across the page. This discourages screenshots, unauthorized sharing, and forwarding while still allowing the intended user to read and use the content.

How it works: The content owner sets a confidentiality level when publishing — Internal, Confidential, or Store-Specific Confidential. The SET Loop rendering layer applies the appropriate treatment automatically for that audience.

This concept sample shows the watermark in place. In production, this would be tied to the user's authenticated role and the publisher's content protection setting.
