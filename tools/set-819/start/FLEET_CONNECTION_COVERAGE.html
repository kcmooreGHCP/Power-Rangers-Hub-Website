The one-click run

1. Register the approved authorities. In InDesign, open each completed T1–T5 map and use 3D Register Current Map as Tier / Prototype Authority.
2. Run the full fleet. Use 3E Run Full Fleet Backbone + Connection Coverage. SET reads the small indexed store snapshots—never the giant fleet CSV inside InDesign.
3. Read the result. The dashboard and Excel workbook open automatically.
4. Refresh after each new prototype. Register the new authority, then use 3G Refresh Rollup Only.
