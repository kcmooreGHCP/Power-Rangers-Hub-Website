SET LOOP RC12.3

Cleaner store guide. Interactive navigation. Governed CC Library intake.

This hotfix keeps the working map and connector engine. It replaces only the store-facing guide logic, SET IRL QR output and the CC Library intake path.

Brand Guide changes

Only mapped work

Unmapped, support, off-floor and no-change records are omitted from the store-facing guide.

Interactive

TOC rows link to room/zone pages. Mapped zone hotspots on the full-store map link to the same pages.

Front + back

Surfaces, floor fixtures and forms use front/back companion files when supplied. Otherwise one approved view fills the page.

Physical cabinet runs

Cabinets are grouped by their actual position on the store map instead of one long numerical list.

Store-only information

Base time, unit time, Blue Yonder IDs and internal status remain in the data export and are removed from the store-facing page.

SET IRL

Compact QR/link blocks replace the long timer copy. The TOC contains a SET IRL directory link.

CC Library rule

A .cclib or .cclibs file is a library transfer/archive package. SET cannot map directly from that package as though it were a PNG folder.

  1. Use the launcher button CC Library Intake + Base Hours.
  2. Select the library package for controlled storage.
  3. Select the local folder containing exported PNG, PSD, AI, PDF or SVG copies.
  4. Edit 01_SOURCE/CC_LIBRARY_ASSET_CATALOG.csv to add base minutes, unit minutes, actions and optional front/back files.
  5. Rebuild the Brand Guide.

Action icons

RC12.3 installs a neutral fallback icon set in 01_SOURCE/ACTION_ICONS. Use semicolon-separated values in the asset catalog, for example:

STEAM; HANGER; FORM STYLE

Official company icons can replace the fallback SVGs later without changing the guide script.

Run order

  1. Quit InDesign and run INSTALL_RC12_3.command.
  2. Rebuild SET IRL once so the global and presentation QR files are current.
  3. Connect real team assets or run CC Library Intake.
  4. Open the mapped store file.
  5. Build the store-facing Brand Guide.
  6. Open the generated interactive PDF in 03_OUTPUT and test TOC, map hotspots and SET IRL links.
