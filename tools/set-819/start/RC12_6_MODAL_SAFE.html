RC12.6 — Modal-Safe Front Door

Every engine now starts only after the launcher has fully closed.

What this fixes

The former launcher ran the selected script inside the button callback while InDesign still considered the launcher modal. That blocked document creation, saving and report actions.

Retest

  1. Open the current working map.
  2. Run CHECK THE FULL STORE.
  3. Run BUILD THE STORE-FACING BRAND GUIDE.

No remapping is required.
