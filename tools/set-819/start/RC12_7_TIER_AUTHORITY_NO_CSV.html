RC12.7 — Lower-tier build without a CSV

The Tier 1 authority INDD already contains the physical connectors and mapped presentation intelligence. The new prototype path duplicates that governed backbone directly.

Prototype Copy — recommended for T2 prototype
Uses the embedded Tier 1 connectors. No CSV is requested. Choose whether to carry mapped visuals as TIER REUSE REVIEW or keep only the physical backbone.
Indexed Store Shell
Enter a store number. SET automatically finds its per-store connector CSV in the prepared fleet index and uses the matched line map when available.
Advanced Manual CSV
Retained only for unusual test data or an external connector file.

Run it

  1. Open the approved Tier 1 authority map.
  2. Run the main SET launcher.
  3. Choose E — Build Lower Tier from Authority.
  4. For a T2 prototype, keep the first mode selected.
  5. Review all carried visuals marked TIER REUSE REVIEW.

The output and audit are saved in the existing ~/Documents/SET_819 workspace.
