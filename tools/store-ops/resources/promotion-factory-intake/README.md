# Promotion Factory intake

Place approved source files here for structured review. Do not add credentials, mailbox exports, private messages, or unrestricted server copies.

## Priority sources

1. **General marketing standards PDF**
   - Definitions and rules for promotional, everyday, pulsed, navigational, and creative marketing.
2. **Two or three promotional Brand Guide examples**
   - Include different brands or campaign types when possible.
3. **Campaign history CSV**
   - Ideally January 2025 through July 2026.
4. **MRF / Smartsheet export**
   - CSV or XLSX with request, approval, proof, quantity, market, and timing fields.
5. **Approved proof packages**
   - PDF, PNG, or JPG exports are preferred over email or mailbox access.
6. **Internal source-location reference**
   - A text file describing the approved server path and folder pattern. Do not copy the whole server into this repository.

## Handling

- Preserve the original filename.
- Add the source owner and export date to a companion note when they are not encoded in the file.
- Use approved, final, or clearly labeled working references only.
- The current prototype reads local browser files for review; it does not upload or connect to internal systems.
- Live Smartsheet, server, or email access requires formal approval, service authentication, and a production data-retention decision.

## Starter CSV

Use `promotion-intake-template.csv` when a source export is unavailable. Blank values remain unresolved; SET must not infer them.
