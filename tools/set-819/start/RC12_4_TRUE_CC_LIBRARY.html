RC12.4 — True CC Library Workflow

Wider launcher. Real CC Library staging. Local automation copies without manually exporting the entire library first.

What changed

The main launcher now uses two columns so every action fits without becoming excessively tall.

The prior .cclibs + local folder intake assumed you already had individual files. RC12.4 adds a staging-and-capture workflow for a real cloud Library.

Use it

1. In the SET launcher, choose 3B True CC Library Staging + Capture.
2. Prepare a wide staging document.
3. Open Window → CC Libraries and choose the approved Library.
4. Drag the graphics needed for the pilot into the numbered frames.
5. Run Capture All Placed Library Graphics.
6. SET exports local PNG automation copies and updates 01_SOURCE/CC_LIBRARY_ASSET_CATALOG.csv.

Why there are local copies

The Creative Cloud Library remains the governed reusable source. SET needs ordinary local files for thumbnail indexing, Match Board, automated Brand Guide placement, front/back companion logic, timing metadata and action icons. The local PNGs are derived automation copies—not a replacement for the Library.
