Fixture Template → Tier Authority → Fleet Intelligence

Three levels. One connected record. No duplicate workflows.

The distinction that makes the system work

3C — Fixture Template

Defines what the physical fixture is: cabinet, surface, form, rack, outpost, dimensions, front/back requirement and export rule.

3D — Tier / Prototype Authority

Defines where those fixture templates live together in the approved T1, T2, T3 or format map by room and zone.

3E — Fleet Intelligence

Determines which stores have those templates and arrangements, what can share, what needs mirrored review and what has no authority match.

Build the tier authorities

1. Open the calibrated T1 mock-store map. Register / refresh Smart Backbone with 3C.
2. Run 3D. Name it T1 Mock Store, mark it Draft or Approved Authority, and create the blank authority shell.
3. Repeat with each real tier map. T2 must use the real T2 line/space map. Continue through all tiers or formats that physically differ.
4. Run 3E. The fleet tool compares every store data shell against all registered authorities.
REAL T1 MAP → T1 AUTHORITY REAL T2 MAP → T2 AUTHORITY REAL T3 MAP → T3 AUTHORITY ↓ 755 STORE TEMPLATE SHELLS ↓ EXACT / REVIEW / MIRROR REVIEW / NO MATCH ↓ REUSABLE TRANSLATIONS + EXCEPTION QUEUE

OutputPurpose

Blank authority INDD/PDFSmall reusable architecture + connector shell with mapped floorset visuals removed.
AUTHORITY_MASTER.csvGoverned list of all approved and draft tier authorities.

What 3E creates for every store

OutputPurpose
STORE_TEMPLATE_SHELL.csvSmall store-specific record of every template, room, zone, side and authority match.
STORE_ROOM_ZONE_SIGNATURES.csvIdentifies identical room/zone fixture arrangements that can share translation.
STORE_TEMPLATE_PROFILE.jsonConnector counts, exact matches, review matches and best authority.

These are deliberately lightweight. SET does not create hundreds of heavy InDesign files before a store needs one.

How sharing is decided

StatusMeaning
EXACTSame reusable template plus compatible room/zone context.
REVIEWSame fixture class/code or same template in a different context. FV or Space Planning confirms.
MIRROR REVIEWSame physical template but opposite side/orientation.
NO AUTHORITY MATCHStore has a fixture or arrangement not yet represented by a registered tier authority.

SET exposes the gap. It does not invent the translation.
