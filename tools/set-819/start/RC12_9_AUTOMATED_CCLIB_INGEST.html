Automated Creative Cloud Library intake

No staging document. No one-by-one drag/drop.

Normal process

  1. Open the SET launcher.
  2. Choose 3B Auto-Ingest .cclib / .cclibs.
  3. Select the exported offline library package once.
  4. Wait for the ingest report.
  5. Refresh or reopen Match Board.

What SET creates

  • 01_SOURCE/CC_LIBRARY_AUTO/<library>/AUTOMATION_ASSETS
  • 04_REPORTS/ASSET_INDEX.csv
  • 01_SOURCE/CC_LIBRARY_ASSET_CATALOG.csv
  • 04_REPORTS/CC_LIBRARY_AUTO_INGEST_REPORT.html

Governance

The original .cclib/.cclibs package is preserved. Local PNG renditions are the SET automation layer for previews, map placement and Brand Guide output. Base minutes, unit minutes, action icons, front/back pairing and approval status remain in the catalog rather than being hard-coded into the library package.

When the archive is not locally readable

SET stops cleanly and creates an escalation report. It does not fall back to manual staging. The production alternative is an approved Adobe Libraries API/enterprise integration or an Adobe-supported export service.
