RC12.8: A true T2 needs a true T2 target.

The tool no longer treats a duplicate of the Tier 1 footprint as an actual lower-tier map unless you explicitly choose Concept Copy.

What happened in RC12.7

The script copied the open Tier 1 INDD, carried its 154 connectors and 105 mapped relationships, and labeled the copy for T2 review. Because no T2 architecture or target connector backbone was supplied, the output was a Tier 1 concept copy, not a true T2 map. The report then failed because ExtendScript does not support Array.map.

Choose the correct path

True Target INDD

Choose the actual T2 InDesign map containing the target architecture and embedded SET connectors. Exact room + zone + placement matches carry forward as TIER REUSE REVIEW.

True Target Line / Space Map Only

Choose the actual T2 line map and optional space map. SET creates a clean architecture shell and does not copy Tier 1 connectors or visuals.

Indexed Store Shell

Enter a store number. SET uses that store's indexed connector snapshot and matched line map.

Concept Copy of T1

Use only when the lower tier intentionally shares the Tier 1 footprint or when you need a planning concept. The output is labeled CONCEPT — T1 FOOTPRINT.

Recommended next test

  1. Install RC12.8.
  2. Open the approved Tier 1 authority.
  3. Run E — Build Lower Tier.
  4. Select True Target INDD when a real T2 SET map exists, or True Target Line / Space Map Only when only the architecture exists.
  5. Do not use Concept Copy as proof of a real T2 layout.
